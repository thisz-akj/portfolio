Hamira Signature (loading-screen signature)
----------------------------------------------------------------
The loader signature uses the free Google font Yellowtail. Hamira is also a Dirtyline
font and is very likely personal-use only — buy a commercial licence first. Then:
  1. Save it here as hamira-signature.woff2
  2. Add this rule near the top of src/app/globals.css:
       @font-face { font-family: "Hamira Signature"; src: url("/fonts/hamira-signature.woff2") format("woff2"); font-display: block; }
The signature already lists "Hamira Signature" first, so it switches automatically.
